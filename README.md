# CinemaHere — макет онлайн-кинотеатра

Откройте index.html в браузере. Сайт статический; изображения и видео подключаются по путям относительно index.html.

## Структура

- index.html, styles.css, app.js — страницы, оформление и поведение.
- media-config.js — пути к логотипу, постерам, кадрам серий и видео.
- supabase-config.js — адрес и публичный ключ сервиса аккаунтов.
- supabase-comments.sql — таблица комментариев и правила доступа.
- supabase-favorites.sql — таблица избранного с синхронизацией аккаунта.
- assets/logo/ — логотип.
- assets/posters/ — постеры фильмов, сериалов и аниме.
- assets/episodes/ — кадры эпизодов в папках series/{id}/ и anime/{id}/.
- assets/videos/trailers/ — трейлеры.
- assets/videos/films/ — полнометражные фильмы.
- assets/videos/series/{id}/ и assets/videos/anime/{id}/ — видео серий.

## Как добавить постер или логотип

Скопируйте файл в assets/posters/ и укажите путь в media-config.js внутри CINEMAHERE_ASSETS.posters. Для первого фильма пример:

    "film-1": "assets/posters/film-1.jpg"

Можно использовать JPG, PNG или WebP. Чтобы заменить логотип, положите файл в assets/logo/ и измените поле logo в media-config.js. Для кадров серий используется ключ вида series/series-1/s01e01; файл можно положить по пути assets/episodes/series/series-1/s01e01.webp.

## Как подключить видео

Трейлеры хранятся отдельно в поле trailer. Полный фильм указывается в поле movie. Для серии добавьте ссылку в episodes, используя ключ вида s01e01 (первый сезон, первая серия):

    "film-6": { trailer: "https://rutube.ru/video/ID_ТРЕЙЛЕРА/", movie: "https://rutube.ru/video/ID_ФИЛЬМА/" }

    "series-5": {
      seasons: [12, 12, 12, 12, 12, 12, 12, 12],
      episodes: {
        "s01e01": "https://rutube.ru/video/ID_СЕРИИ_1/",
        "s02e01": "https://vkvideo.ru/video_ext.php?oid=-123456&id=789012&hash=..."
      }
    }

Поддерживаются ссылки на страницу ролика или embed-ссылки RUTUBE и ссылки video_ext.php VK Видео. Плеер преобразует ссылку страницы RUTUBE во встроенный плеер. Если источник эпизода пустой, серия остаётся в каталоге, а плеер сообщит, что видео не подключено.

Список сезонов и серий настроен в media-config.js для всех позиций, кроме «Наруто». Добавляйте только видео, опубликованные правообладателем или с его разрешения. Локальный MP4 можно указать относительным путём, например movie: "assets/videos/films/film-6.mp4".


## Аккаунты и комментарии

Аккаунты, комментарии и избранное хранятся в Supabase. Комментарии видны вошедшим пользователям, а избранное привязано к аккаунту и синхронизируется между устройствами. Без подключения Supabase регистрация, комментарии и избранное не работают.

1. Создайте проект в [Supabase](https://supabase.com/dashboard).
2. В проекте откройте **SQL Editor**, вставьте содержимое `supabase-comments.sql` и запустите его. Скрипт создаст таблицу и политики доступа для обсуждений.
3. Если комментарии уже настроены, повторно запускать `supabase-comments.sql` не нужно. В **SQL Editor** выполните `supabase-favorites.sql`: он создаёт отдельную таблицу избранного, и каждый аккаунт видит только свой список.
4. Откройте **Project Settings → API Keys** (или **Integrations → Data API**) и скопируйте **Project URL** и **Publishable key**. Для старого интерфейса Supabase подойдёт также публичный `anon` key.
5. Вставьте эти два значения в `supabase-config.js` в поля `url` и `anonKey`.
6. В **Authentication → URL Configuration** задайте адрес CinemaHere как **Site URL** и добавьте адрес сайта в **Redirect URLs**, например `https://maxnikolaev09-netizen.github.io/CinemaHere/`. Подтверждение почты можно оставить включённым: после регистрации перейдите по ссылке из письма, затем войдите на сайт.
7. Опубликуйте обновлённые `index.html`, `app.js`, `styles.css`, `supabase-config.js` и SQL-файлы вместе с остальными файлами проекта. SQL-файлы нужны для настройки базы; на сайте они не запускаются.

**Важно:** `supabase-config.js` содержит только публичный Project URL и Publishable/anon key. Никогда не помещайте в него `service_role` или secret key — они дают полный доступ к данным. Политики RLS в SQL ограничивают доступ к комментариям и проверяют автора на стороне базы.

Если проверяете сайт локально, откройте его через локальный веб-сервер, а не как `file:///...`. Добавьте этот локальный адрес в Supabase **Redirect URLs**. Пароли не сохраняются в файлах сайта: ими управляет Supabase Auth.

Оплата не подключена. Публикуйте только видео, на которые у вас есть права; для большого каталога используйте видеохостинг или CDN.

## Кадры в верхней части страницы просмотра

Кадры берутся из assets/Cadr и сопоставляются с фильмами, сериалами и аниме по ID в media-config.js, в блоке frames. Для выбранной серии применяется кадр её сериала; при необходимости можно задать отдельный путь в episodes.
